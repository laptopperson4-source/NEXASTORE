Payment mechanics

How payments work

Last updated: 7 September 2026 · Read before sending any crypto

Network

Paid apps are priced in USDT on Polygon (chain ID 137). USDT on other networks (Ethereum, BSC, TRC-20, etc.) is not accepted for NexaStore unlocks and can be lost if sent to the wrong network.

Who receives the money

In the default flow, the buyer sends USDT to the developer payout wallet shown for that app (Polygon address). NexaStore’s stated model is direct to developer with no platform commission on that transfer.

If a developer has not set a payout wallet, a platform fallback address may be used so checkout can still complete. We document that clearly in the product when it applies.

On-chain transfers are final. There is no card-style chargeback.

Fees

You need enough Polygon USDT for the app price and a small amount of POL for network gas. Gas is paid to the network, not to NexaStore as a commission.

Risks (honest)

  • Send only the listed amount on Polygon to the address shown in checkout.
  • Wrong network or wrong address usually cannot be reversed.
  • The marketplace is early; treat small test amounts as the safe way to learn the flow.
